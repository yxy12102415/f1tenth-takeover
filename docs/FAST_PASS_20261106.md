## Initial diagnostic candidate

Opt-in `TAKEOVER_FAST_PASS_GEOMETRY=true` adds a cost on the dense approximate
actual route-plus-offset curvature inside SQP. The existing cost mainly
penalizes offset derivatives and reference deviation; a low-curvature spatial
solution can permit a higher speed under the UNCHANGED lateral-acceleration
budget. Analytic derivatives and final hard residual checks are retained.
This is a cost preference, not a new safety certificate or permission to
ignore curvature/map/body/MPC checks. Default remains false pending testing.
